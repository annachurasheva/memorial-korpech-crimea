# data/geo — справочник малых населённых пунктов призыва

Этот каталог готовит данные для **поискового бота**: списки сёл, деревень,
станиц, хуторов, аулов, кишлаков и посёлков, откуда призывались/происходили
бойцы. Бот ищет по ним «земляков» в социальных сетях и публичные социальные
точки (группы, школы, библиотеки, администрации).

## Правила

1. **Только малые населённые пункты** (село, деревня, станица, хутор, аул,
   кишлак, посёлок). **Города и крупные локации не включаем** — поиск по ним
   малоэффективен.
2. Источник — поле `place_birth` (место рождения) из сырых CSV `data/raw/krim-front/`.
   Колонка `conscription_location` (военкомат призыва) в текущих выгрузках пуста,
   поэтому для сельских жителей место рождения принимаем как место призыва.
3. Названия записаны **как в донесении** (возможны искажения из сканов).
   Перед публикацией каждое сверяется — см. `docs/VERIFICATION_INSTRUCTION.md`.
4. Этот справочник **не** является картотекой. Он вспомогательный, для задач
   волонтёрам и боту. Карточки — в `data/mem_OK_file_cabinet.json`.
5. Список неполон и пополняется по мере загрузки новых CSV.
