# data/geo/settlements.md

Справочник малых населённых пунктов призыва для поискового бота.
Источник: `place_birth` из `data/raw/krim-front/*.csv` (место рождения бойцов
Крым-Фронта). Города и крупные локации исключены — только села/деревни/
станицы/хутора/аулы/кишлаки/посёлки.

Названия даны **как в донесениях** (с возможными искажениями из сканов).
Сверка — по `docs/VERIFICATION_INSTRUCTION.md`.

## Примечание
- Регион помечается как указано в донесении. Часть названий — с искажениями
  («Егорвыкский», «Понежецаевский» — вероятно, Егорлыкский, Понежукаевский),
  их надо сверить перед использованием.
- Список — стартовый, пополняется по мере загрузки новых CSV.
- В отдельный блок «Прочие регионы РСФСР» собраны разрозненные малые пункты,
  чтобы не плодить секции для единичных записей.
