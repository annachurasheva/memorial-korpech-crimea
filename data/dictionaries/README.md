# Словари подмены для конвертера CSV → Markdown
Координата: `annachurasheva/memorial-korpech-crimea` · `data\dictionaries\README.md` · v2 · 2026-09-08

## Назначение
Эти JSON-файлы используются скриптом `scripts/csv-to-markdown.mjs` для автоматической расшифровки архивных сокращений в полные, уважительные и понятные современному читателю формулировки.

## Структура файлов

### 1. ranks_dict.json (Звания)
**Ключ:** сокращение из CSV (точно как в архиве)  
**Значение:** полное звание для отображения на сайте  
**Пример:** `{"ст. лейтенант": "Старший лейтенант", "мл. сержант": "Младший сержант"}`

### 2. units_dict.json (Воинские части)
**Ключ:** сокращение части из CSV  
**Значение:** полное название с почётными наименованиями и фронтом  
**Пример:** `{"422 ап 157 сд": "422-й артиллерийский полк 157-й стрелковой Неманской дивизии 5-й армии 3-го Белорусского фронта"}`

### 3. locations_dict.json (География и локации) ⚠️
**Ключ:** историческое название из CSV (напр. "Ворошиловград", "Чкаловская обл.")  
**Значение:** современное или уточненное название для понимания текущим поколением  
**ВАЖНО:** Этот словарь **не заполняется вручную** в этом репозитории. Он формируется и обновляется внешним процессом (отдельный репозиторий/скрипт с парсингом исторических названий) и импортируется сюда как готовый файл. Не удаляйте его, если он присутствует.

### 4. burials_primary.json / burials_current.json
**Ключ:** место захоронения из CSV  
**Значение:** нормализованное название для тегов и навигации (например, для группировки "выс. 66,3").

## Как пополнять (кроме locations_dict.json)
1. Запустите скрипт: `node scripts/csv-to-markdown.mjs`
2. Откройте `scripts/logs/errors.json` — там перечислены нераспознанные значения.
3. Найдите правильное полное название в архивах.
4. Добавьте пару "ключ-значение" в соответствующий JSON.
5. Запустите скрипт снова.

## Правила форматирования JSON
- Сохраняйте кодировку **UTF-8**.
- Используйте только двойные кавычки `"`.
- Запятая после последней пары ключ-значение **не требуется** (и вызовет ошибку).
- Перед коммитом проверяйте синтаксис (например, на [jsonlint.com](https://jsonlint.com/)).
