### 📋 ЗАПИСКА ДЛЯ НОВОГО ДИАЛОГА (Скопируйте текст ниже)

**Контекст:**
Пользователь из РФ. ОС Windows 10 (кастомная), терминал PowerShell 7 (pwsh). Хостинг — Tencent EdgeOne Pages. DNS-домен управляется через Cloudflare. 

**Главная задача:** 
Выпустить и установить SSL-сертификат для домена `info.roses-crimea.ru`, который привязан к проекту в EdgeOne Pages. Деплой самих файлов (папка `dist` от Astro) — это сопутствующая задача, но файлы уже умеют загружаться. Главная проблема — именно SSL.

**В чем проблема (почему мы здесь):**
1. Автоматический выпуск бесплатного сертификата через веб-консоль EdgeOne Pages зависает на 12+ часов и выдает ошибку (серверы проверки Let's Encrypt не могут достучаться до домена из-за сетевых ограничений/блокировок).
2. Ручная загрузка сертификата через веб-консоль Tencent Cloud SSL невозможна: при попытке входа в раздел SSL консоль требует привязать банковскую карту, которой у пользователя нет.
3. Суб-пользователь Tencent Cloud имеет отключенный вход в консоль (только API), настроен MFA. Из-за этого команда `edgeone login` падает с ошибкой `status code 567`.
4. У пользователя есть готовый SSL-сертификат (Let's Encrypt), сгенерированный локально через `Posh-ACME` (файлы `fullchain.cer` и `cert.key` лежат в `C:\PS_Config`).

**Что уже пробовали и на каком этапе находимся:**
*   **Попытка 1 (Веб-консоль EdgeOne):** Автоматический выпуск не работает (зависает).
*   **Попытка 2 (Утилита `eo-maker-deploy`):** Права суб-пользователя настроены (кастомная CAM-политика с `teo:*`, `ssl:*`, `dnspod:*`). Верификация `eo-maker-deploy check-permissions` проходит успешно (все 3 пункта зелёные). API-токен EdgeOne сгенерирован и записан в `.env`. Однако при попытке деплоя с флагом SSL, утилита падает, так как внутренний механизм EdgeOne не может выпустить сертификат, либо требуется авторизация `edgeone login`, которая падает с ошибкой 567.
*   **Попытка 3 (Использование `tccli` для ручной загрузки):** Установлен `tccli`, настроен профиль суб-пользователя. Есть готовый Node.js-скрипт или понимание, как через API загрузить сертификат в SSL Tencent Cloud и привязать его к EdgeOne через `ModifyHostsCertificate`. Но этот шаг еще не завершен.

**Что нужно от нового диалога:**
Помочь завершить настройку SSL. 
Наиболее перспективный путь — использовать готовый сертификат (`fullchain.cer` + `cert.key`) и загрузить его через API (например, через `tccli` или Node.js SDK), минуя веб-консоль и не используя `edgeone login`. 
Либо предложить иной рабочий способ обойти блокировку автоматического выпуска SSL в EdgeOne.
