# Контекст темы Retypeset для ИИ-агента (Coder02)

## 1. Правила Front Matter (Строго обязательно)
При генерации Markdown-файлов для `src/content/posts/memorial/` используйте только следующие поля:
- `title`: (string) Обязательно. ФИО персоны.
- `published`: (date) Обязательно. Дата из CSV (формат YYYY-MM-DD).
- `lang`: (string) Обязательно. Указывать `ru`.
- `abbrlink`: (string) Обязательно. Формирует URL. Только строчные буквы, цифры и дефисы (напр. `camo-506255127`). Без пробелов и спецсимволов.
- `tags`: (array) Опционально, но рекомендуется для навигации (rank, unit, burial).
- `description`: (string) Краткое описание для списков и SEO.

## 2. Разрешенные Markdown-конструкции темы
Используйте только следующие элементы для форматирования тела статьи:
- **Таблицы:** Стандартный синтаксис Markdown (`| Заголовок | Данные |`).
- **Блоки примечаний (Admonitions):**
  - `> [!IMPORTANT]` — для ключевой информации (причина выбытия, звание).
  - `> [!WARNING]` — для недостающих данных или требующих уточнения.
  - `> [!NOTE]` — для нейтральных исторических справок.
- **Сворачиваемые разделы:**
  ```markdown
  :::fold[Заголовок раздела]
  Содержимое, которое можно скрыть (например, архивные реквизиты).
  :::
