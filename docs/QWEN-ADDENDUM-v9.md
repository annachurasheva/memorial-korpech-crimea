## А3. Приёмка (механика, проверенная на dashboard-mem-2026)
- Зелень песочницы = NOT TESTED, не PASS.
- Закрытие = строка Кодера «DONE + <хэш коммита владельца>».
- Отчёт: reports/report-TASK-NNNN.md, блоки TASK / CHANGED FILES /
  CHANGES / ENV / DIFF / RESULT / NOTES; материалы — полным текстом
  по §7.3 v0.4. Внутренние рассуждения в отчёт не выводятся.
- ENV обязан содержать реальные node -v / pnpm -v; расхождение с
  .nvmrc или lockfile (прецедент: node 20.20.2 при .nvmrc 24.5.0) —
  строкой в NOTES, молча продолжать запрещено.
