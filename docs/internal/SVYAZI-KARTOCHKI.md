# SVYAZI-KARTOCHKI.md · карта связей карточки павшего · v1 · 2026-09-22
Собрано Дельтой-3 из осмысленных с владельцем ветвлений. Уровень = узел,
ветвление = правило или код очереди. П1 = формулировка документа неприкосновенна.

## Уровень 0 · Ядро (идентичность)
- id ← document_id ЦАМО (вечный, не меняется).
- slug = bitva-za-krym-1942-<транслит-ФИО>-<pmn|obd>-<document_id>;
  ветвления: первый slug закреплён навсегда; неизменяем (кормит бота);
  маркеров смерти нет; кириллицы в slug/filename/URL нет нигде.
- filename = slug (единое правило).
- status: inbox | processed | rejected | needs_manual_review; draft: true/false.
- Рёбра: id → очередь; slug → бот-зеркало; карточка → витрины и ленты.

## Уровень 1 · Персона
- ФИО кириллицей (П1) → поисковый индекс: только Фамилия+Имя,
  подстрока, регистронезависимо, ё=е; отчество вне индекса.
- Дата гибели: вид человеческий («21 марта 1942»), не ISO;
  «не позднее X» → tail: true; вне окна и вне хвоста → date_out_of_window.
- Причина: только поле «Причина» по документу; в заголовок/description/
  ленты/slug не тиражируется.
- place_birth: raw как в источнике; современные атрибуции (РФ/ЛНР/Украина)
  не маппятся, не правятся.
- Звание: rank_raw (П1) → словарь ranks → rank_norm; дыра → уточнение.

## Уровень 2 · Служба
- warunit: unit_raw (П1) → units_registry → unit_norm → unit_id.
- Иерархия: фронт (СКФ) → армия (44 А) → дивизия (сд) → полк (сп/ап).
- Дыра словаря → код unit_gap; выдумка запрещена.
- unit_id + вилка 01.12.1941–19.05.1942 → витрина «Сослуживцы».

## Уровень 3 · Захоронение (цепочка, R-12)
- primary_burial: raw → словарь burials (kind: primary) → norm.
  Точки: выс. 66,3 (Окопная), выс. 71,3, Корпечь (6 вариантов написания),
  Ак-Монай, Тулумчак, Кай-Асык, домик где умер от ран.
- burial.history[]: {place, date_approx, kind: primary|exhumation|reburial}.
- current_norm + current_status → memorial_id → справочник memorials
  (type: мемориал|памятник|захоронение; Корпечь = памятник).
- Нет ссылки → код memorial_unlinked; карточка создаётся.
- Перезахоронение __.04.1944 = событие уровня 3, не оси времени.
- Мультимемориальность с рождения: батч любого мемориала обязан проходить.

## Уровень 4 · Камень (R-09, R-14)
- engraved: yes | no | unknown; null запрещён.
- unknown → код stone_check; публикацию НЕ держит.
- Трек плиты: заявка подана (documented) → одобрена (approved) → высечен (engraved).
- yes на 2026-09-20 = 59 имён учётки №1360; ВМЦ 82-390/2014.
- Увековечен elsewhere (R-19): engraved yes + memorial_id того памятника
  (Батальное, Фронтовое, Приморское, Шабани, Парпач, Феодосия).
- Сверка камня = причина (г) правки опубликованной карточки.

## Уровень 5 · Призыв (R-13)
- conscription_location: raw (байт-в-байт, П1) → словарь locations → norm
  → modern (современное имя, скобка-справка, не подмена).
- Нет modern → modern_gap; в поле часть вместо места → conscription_not_place;
  «Чкаловск» без области → location_ambiguous (Чкалов ≠ Чкаловск).
- loc_map: 15 строк + резерв; правка коммитом data:, приёмка владельцем.

## Уровень 6 · Источники и слияния (D-6, D-7, веса M8)
- sources[]: {org, url}; primary_url; индекс slug = pmn|obd.
- Совпадение ФИО+дата гибели = ОДНА карточка; второй портал в sources[].
- Один портал, индексы разные → STOP, список оператору (автослияние запрещено).
- Разные порталы, 3–4 позиции → слияние: индекс и фото = pmn;
  канон формулировок = ОБД (П1).
- Вес 1 (ЦАМО через ОБД/ПМН) создаёт карточки; вес 2 (форум, txt 28-5-2026)
  только перекрёст; вес 3 = методики сверки.
- Фото pmn (офицерские карточки) — вручную владельцем, вне конвертера.
- v_dupes (ФИО+дата) → операторский список.

## Уровень 7 · Атрибуция (M9 переписано)
- Автор списка/материала: {id, name, type: персона|сообщество|музей|архив|
  библиотека, credentials, access: публичный|по записи|служебный,
  license_note, link}.
- Слой 1: объект author автора шаблона (name/credentials/affiliation/bio).
- Слой 2: наша schema (коллекция авторов или поле карточки);
  попап «что это» только в слое 2; data-driven: author_id пуст → блок не рендерится.
- «Взяла в RSL — материал публичен» = type: библиотека + access + license_note.
- Боковых реестров атрибуции нет (инъекция authors.yaml выведена).

## Уровень 8 · Очередь уточнений (при карточке, не вместо)
- Запись clarify.queue.json ссылается на id карточки; карточку не заменяет.
- Коды: conscription_location_empty; current_burial_empty; missing;
  stone_check; snippet_gap; modern_gap; pow_check; unit_gap;
  memorial_unlinked; location_ambiguous; conscription_not_place;
  date_out_of_window.
- [БезВЕСТИ]: missing: true + код missing; карточка processed;
  публикация — решение владельца.
- Плен: needs_manual_review + draft: true + pow_check; публикация — админ.

## Уровень 9 · Родные
- relatives[]: {name, address (адрес похоронки), relationship}.
- Волонтёрские изыскания (имя ждавшего + адрес) = причина (а) правки опубликованной.
- address → сниппет ОК (варианты репоста).

## Уровень 10 · Показ (витрины, В2)
- Карточка = чистый лист: ИМЯ заголовком; нажатие заголовка → главная
  (дополнительных стрелок нет); без шапки сайта; без комментариев/giscus.
- Сослуживцы (unit_id + вилка); Одна могила (memorial_id, страница справочника);
- Общий список (сортировка — решение владельца, R-06: рекомендовано
  unit_norm → дата гибели → фамилия); Поиск (Фамилия+Имя).
- Слой 1: двери = теги (механика шаблона); слой 2: своя сборка.

## Уровень 11 · Распространение
- ОК: карточка = источник 3 вариантов сниппета (ФИО, rank_norm, unit_norm,
  даты, адрес похоронки, фото); нет поля → snippet_gap.
- RSS/Дзен: enclosure ≥700 px, guid стабилен, UTF-8; description без
  маркеров смерти; К-03 (динамическая локация) после 50+.
- Бот-зеркало (Telegram-транзит): кормится slug → slug неизменяем.
- Лента второго слоя пуста до возврата карточек из черновиков.

## Уровень 12 · Жизненный цикл (R-01)
- Создание: строка веса 1 с ФИО и датой гибели = карточка всегда.
- published → правки админа по причинам (а)…(г) → снять с публикации можно →
  повторная публикация запрещена навсегда.
- draft: true → не публикуется; черновики не попадают в dist и ленты.

## Свод рёбер (граф одной строкой каждого ребра)
id→очередь(id); slug→бот; unit_id→сослуживцы; memorial_id→одна могила;
engraved→трек плиты; primary→history[]→current; raw→словари→norm→modern;
sources[]→слияния(оператор|pmn-канон); author.id→карточка/пост→попап(слой 2);
relatives.address→сниппет ОК; status/draft→публикация→ленты→Дзен/RSS;
карточка→витрины→поиск; веса(1|2|3)→создание|перекрёст|методика.
