# Словари подмены для конвертера CSV → Markdown

## Назначение
Эти JSON-файлы используются скриптом `scripts/csv-to-markdown.mjs` для автоматической расшифровки архивных сокращений в полные, уважительные формулировки.

## Структура

### ranks_dict.json
**Ключ:** сокращение из CSV (точно как в архиве)  
**Значение:** полное звание для отображения на сайте

**Пример:**
```json
{
  "ст. лейтенант": "Старший лейтенант",
  "мл. сержант": "Младший сержант",
  "красноармеец": "Красноармеец"
}
```

### units_dict.json
**Ключ:** сокращение части из CSV  
**Значение:** полное название с почётными наименованиями и фронтом

**Пример:**
```json
{
  "467 кап": "467-й корпусной артиллерийский полк",
  "422 ап 157 сд": "422-й артиллерийский полк 157-й стрелковой Неманской дивизии 5-й армии 3-го Белорусского фронта"
}
```

### burials_primary.json
**Ключ:** место первичного захоронения из CSV  
**Значение:** нормализованное название для тегов и навигации

**Пример:**
```json
{
  "Крымская АССР, Ленинский р-н, выс. 66,3": "выс. 66,3 (Ленинский р-н)"
}
```

### burials_current.json
**Ключ:** место текущего захоронения  
**Значение:** уточнённое название (мемориал, перезахоронение)

## Как пополнять

1. Запустите скрипт: `node scripts/csv-to-markdown.mjs`
2. Откройте `scripts/logs/errors.json` — там нераспознанные значения
3. Найдите правильное полное название в архивах
4. Добавьте пару "ключ-значение" в соответствующий JSON
5. Запустите скрипт снова

## Правила
- Сохраняйте UTF-8 кодировку
- Запятая после последней пары **не требуется**
- Кавычки только двойные `"`
- Проверяйте синтаксис на [jsonlint.com](https://jsonlint.com/)
```
