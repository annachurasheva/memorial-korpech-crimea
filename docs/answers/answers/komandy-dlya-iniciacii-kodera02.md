# TASK-0200: Формирование начального словаря воинских званий

## 1. Контекст
В папке `data/csv/` (включая вложенные папки) находятся исходные файлы с данными о павших. В колонке `rank` встречаются как стандартные звания, так и сокращения, а также специфические должности/звания (например, "интендант 1 ранга", "мл. политрук", "командир отделения").
Для корректной генерации карточек необходим файл-словарь `data/dictionaries/ranks_dict.json`.

## 2. Цель
Проанализировать все CSV-файлы в `data/csv/`, извлечь уникальные значения из колонки `rank` и сформировать валидный JSON-файл `data/dictionaries/ranks_dict.json` с правилами подмены.

## 3. Требования к выполнению

### 3.1. Анализ данных
- Прочитать все файлы `*.csv` в директории `data/csv/` и её подпапках.
- Собрать список всех уникальных значений из колонки `rank` (учитывать регистр и пробелы).

### 3.2. Формирование словаря
- Создать файл `data/dictionaries/ranks_dict.json`.
- Для каждого уникального значения создать пару `"ключ": "значение"`.
- **Ключ** должен точно соответствовать написанию в CSV (включая пробелы и регистр, если они встречаются).
- **Значение** должно быть исторически и грамматически корректным полным названием звания/должности для отображения на сайте.

### 3.3. Правила подмены (Примеры)
- `"красноармеец"` → `"Красноармеец"`
- `"ст. лейтенант"` → `"Старший лейтенант"`
- `"мл. политрук"` → `"Младший политрук"`
- `"интендант 1 ранга"` → `"Интендант 1-го ранга"`
- `"техник-интендант 2 ранга"` → `"Техник-интендант 2-го ранга"`
- `"командир отделения"` → `"Командир отделения"` (оставить как есть, но с заглавной буквы, если это устоявшаяся должность).

### 3.4. Обработка неизвестных значений
- Если значение очевидно является опечаткой или крайне редким сокращением, которое невозможно однозначно расшифровать без архивного поиска, оставьте значение как есть (дублируйте ключ в значении) и добавьте в конец файла JSON-комментарий или отдельный массив `"needs_review": [...]` для ручной проверки владельцем. **Не выдумывайте исторические звания.**
