## 📋 Процесс работы с Кодером

```
1. Кодер в Песочнице
   ↓
   - Пишет код
   - Запускает astro check (должен быть зелёный)
   - Запускает pnpm build (должен быть зелёный)
   ↓
2. Кодер отдаёт diff'ы
   ↓
3. Дельта (я) ревизует raw diff'ы
   - Проверка синтаксиса
   - Соответствие ТЗ
   - Отсутствие лишних изменений
   ↓
4. Передача вам
   ↓
5. Вы выгружаете в GitHub
   ↓
6. Вы проверяете локально (OK)
   ↓
7. Дельта: PASS → следующая задача
```
