Приветствую, руководитель. Это отличная и очень важная задача.

У вас есть 18 смысловых полей (исключая крайние «Заголовок» и «Дата»). Чтобы грамотно распределить их по шаблону Retypeset, **не меняя его программную структуру (ядро Astro и компоненты темы)**, мы применим следующий принцип разделения данных:

1. **Front Matter (шапка файла `.md`)** — используем только те стандартные поля, которые уже «зашиты» в тему. Они нужны для списков, тегов, формирования красивых URL и SEO.
2. **Тело статьи (Body)** — все биографические и архивные данные оформляем внутри самого текста с помощью расширенного Markdown, который ваша тема уже поддерживает из коробки (таблицы, сворачиваемые блоки `:::fold`, блоки примечаний `> [!IMPORTANT]`).

---

### 1. Распределение по Front Matter (Метаданные)

| Поле CSV | Поле в Front Matter | Зачем это нужно |
| :--- | :--- | :--- |
| `last_name`, `first_name`, `middle_name` | `title` | Заголовок карточки (напр. *«Авдеев Григорий Иосифович»*) |
| `document_id` | `abbrlink` | **Критически важно!** Формирует короткий и уникальный URL страницы (напр. `/posts/506255127/`), чтобы ссылка не ломалась, если вы исправите опечатку в фамилии. |
| `rank`, `warunit`, `cause_of_death` | `tags` | Позволит вам и посетителям фильтровать мемориал по званиям, частям и причинам выбытия (напр. теги: `красноармеец`, `467 кап`, `умер от ран`). |
| `Дата` (из CSV) | `published` | Обязательное поле темы для сортировки карточек по дате добавления в базу. |
| *(генерируется)* | `description` | Краткая сводка для списков и соцсетей (напр. *«Красноармеец 467 кап. Умер от ран.»*). |

---

### 2. Распределение по телу статьи (Визуальная карточка)

Все остальные 12 полей мы размещаем внутри самого файла `.md`, используя фишки вашей темы из документации:
* **Таблицы** — для структурированных данных (ФИО, даты, места).
* **Блоки примечаний (`> [!IMPORTANT]`)** — для выделения причины гибели (эта фишка есть в вашей теме).
* **Сворачиваемые разделы (`:::fold[]`)** — для архивных реквизитов (фонд, опись, дело), чтобы не перегружать основной экран посетителя.

---

### 3. Готовый шаблон файла `.md` (Пример для Авдеева Г.И.)

### ⚠️ Важное техническое предупреждение (Почему мы делаем именно так)

В современных фреймворках (Astro) структура Front Matter строго типизирована в файле `src/content/config.ts`.
Если бы мы захотели добавить в шапку файла *новые* нестандартные поля, например: `rank: "красноармеец"` или `birth_place: "Одесса"`, Astro **выдал бы ошибку при сборке сайта**, пока мы не перепишем ядро темы.

Предложенный мной метод **на 100% соответствует вашему требованию «не менять структуру шаблона»**:
1. Мы используем только стандартные поля темы (`title`, `tags`, `abbrlink`).
2. Всю специфичную мемориальную информацию мы отдаем Markdown-рендереру темы, который уже умеет красиво оформлять таблицы, цитаты и сворачиваемые блоки (`:::fold`).
3. Вам не нужно будет лезть в программный код (`.ts` и `.astro` файлы) — достаточно написать скрипт, который просто берет строки CSV и генерирует из них такие `.md` файлы.
