# Версионирование и теги релизов

## Роли репозиториев
- `memorial-korpech-crimea` — ИСХОДНИК: код сайта, статьи, карточки, словари.
  `dist/` там в `.gitignore` и не коммитится. Ветки: `qwen3-memorial` (рабочая),
  `main` (заморожена по ADR-04), `bak` (слепок донора).
- `mem-2026` — ПУБЛИКАЦИЯ: собранный `dist/`, теги релизов, документы (docs/).
  Исходный код здесь не правится. Remotes: `sourcecraft` (живой хост
  mem-2026.sourcecraft.site) и `origin` (публичное зеркало GitHub).

## Порядок публикации
1. В ИСХОДНИКЕ: `pnpm astro check && pnpm build` (0 errors).
2. Скопировать `dist/` из исходника в рабочую копию `mem-2026`.
3. В `mem-2026`: `git add dist/` и коммит с хэшем исходника (трассируемость):
   `chore: publish built site from dist (source: memorial-korpech-crimea@<хэш>)`
4. Тег: `git tag -a v1.x.y -m "<что изменилось для живого сайта>"`
5. `git push sourcecraft main && git push sourcecraft --tags` (живой хост)
6. `git push origin main && git push origin --tags` (зеркало)

## Контуры и dist/
- dist/ российской сборки выгружается ТОЛЬКО на SourceCraft.
- EdgeOne российским dist/ не обновляется: заморожен до задачи зарубежной сборки.
- Зарубежная сборка (когда будет принята) помечается отдельным суффиксом тега
  (например, v1.x.x-foreign) и выгружается только на EdgeOne.

## Семантика версий
| Версия | Когда |
|---|---|
| `v1.0.0` | Первый подтверждённый релиз на SC (сайт + документы) |
| `v1.0.x` | Правки контента/опечатки |
| `v1.x.0` | Новые разделы, ленты, страницы |
| `v2.0.0` | Несовместимые изменения архитектуры |
Версия = снимок живого сайта. Частые добавления имён не требуют подъёма MAJOR.

## Откат на SC
`git checkout v1.x.y` в `mem-2026` → `git push sourcecraft main`
(или ручная выгрузка `dist/` этого тега). Теги = история состояний живого сайта.

## Правила гигиены
- Коммит-сообщения: `docs:`, `chore:`, `feat:`, `fix:` + суть одной строкой.
- Тег ставится ТОЛЬКО после коммита (аннотированный, `git tag -a`).
- Один тег: `git push <remote> v1.x.y`; все: `git push <remote> --tags`.
- `dist/` в `mem-2026` не игнорируется (это контент); в ИСХОДНИКЕ игнорируется.
