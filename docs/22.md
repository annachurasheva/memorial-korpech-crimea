### 2. ГОТОВЫЙ ПРОМПТ ДЛЯ КОДЕРА02 (Скопируйте и отправьте)

```markdown
# ЗАДАНИЕ: Node.js скрипт конвертации CSV в Markdown (Retypeset)

## Контекст и правила темы (СТРОГО СОБЛЮДАТЬ)
Тема: Retypeset (Astro). Документация: `docs/agent-context-retypeset.md` (выжимка ниже).
1. Front Matter: Обязательны только `title` и `published`. 
2. `abbrlink`: формирует URL. Только строчные буквы, цифры и дефисы (напр. `camo-506255127`).
3. `lang`: указывать `ru`.
4. Markdown-фишки темы, которые нужно использовать:
   - Блоки примечаний: `> [!IMPORTANT]`, `> [!WARNING]`, `> [!NOTE]`
   - Сворачиваемые разделы: `:::fold[Заголовок]\nконтент\n:::`
   - Стандартные таблицы Markdown.

## Цель
Написать скрипт `scripts/csv-to-markdown.mjs`, который:
1. Читает ВСЕ файлы с расширением `.csv` из папки `data/csv/` (имена файлов могут быть любыми, напр. `cvs-001.csv`, `test.csv`).
2. Применяет словари подмены из `data/dictionaries/` (звания, части).
3. Генерирует `.md` файлы в `src/content/posts/memorial/`.
4. Пишет отчет о выполнении и ошибках в `scripts/logs/run.log` и `scripts/logs/errors.json`.

## Логика обработки данных (из CSV)
- `last_name` + `first_name` + `middle_name` → `title`
- `document_type` + `document_id` → `abbrlink` (напр. `camo-506255127`, в нижнем регистре)
- `Дата` → `published`
- `rank` и `warunit` → искать в словарях `.json`. Если не найдено: оставить как есть и записать в `errors.json` для ручной проверки.
- `date_birth` → если есть полная дата, оставить только год. Если пусто → `—`.
- Сформировать блок "Сослуживцы" (группировка по `warunit`).

## Запрещено
- Менять структуру Astro-проекта.
- Удалять или изменять исходные `.csv` файлы.
- Генерировать файлы вне папки `src/content/posts/memorial/`.

## Формат отчета (ОБЯЗАТЕЛЬНО)
### Выполненная операция
`[Название]`
### Изменённые/Созданные файлы
`[Список]`
### Что изменено
`[Кратко]`
### Проверка
`[Результат тестового запуска]`
### Ошибки
`[Список или "Нет"]`
### Требуется решение владельца
`Да / Нет`
### Следующая операция
`Не выполнять. Ожидать отдельный промт.`

## Действие
1. Создай структуру папок `data/csv/`, `data/dictionaries/`, `scripts/logs/`, `src/content/posts/memorial/`.
2. Создай заготовки словарей `ranks.json` и `units.json` с 2-3 примерами.
3. Напиши код `scripts/csv-to-markdown.mjs`.
4. Выполни тестовый прогон (если есть тестовый CSV) или покажи код для проверки.
5. Остановись и выдай отчет.
```
