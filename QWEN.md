# 4. ФАЙЛЫ

по слову «заменить целиком». В ответе каждый файл — код-блок со строкой
«# ФАЙЛ: <путь>»; один блок = один файл.

Команды в отчётах — только PowerShell/Windows. Непроверяемое —
NOT TESTED; угадывание запрещено.
